# Main に追加したコードの意図

## 目的

`Main` に追加したコードは、Re:Mind のトランスコンパイルを開始する前に、コマンドライン引数から入力ファイルと出力ファイルを受け取り、入出力に必要な情報を準備するための前処理です。

## `TargetLang` クラス

`TargetLang` は、生成先のターゲット言語を表す値を定数としてまとめるための内部クラスです。

- `Java` (`java`): Java 向けの出力
- `CSharp` (`cs_`): C# 向けの出力
- `VbNet` (`vb`): VB.NET 向けの出力
- `Mind` (`src`): Re:Mind のソース形式

ターゲット言語を文字列リテラルのまま各所に記述せず、定数で統一して扱えるようにする意図があります。これにより、後続処理で出力先の判定やコード生成器の選択を追加しやすくなります。

## コマンドライン引数の検証

`Main` は、次の 2 つの引数を受け取る想定です。

1. 入力する Re:Mind ソースファイルのパス
2. 生成する出力ファイルのパス

引数の数が 2 個でない場合は `Messages.E00001` を表示して処理を終了します。必要な入力情報が不足した状態で処理を進めないための検証です。

## 入力ファイルの確認と読み込み

1 個目の引数を入力ファイル名として取得し、`File.Exists` でファイルの存在を確認します。ファイルが存在しない場合は、`Messages.E00002` とファイル名を表示して終了します。

ファイルが存在する場合は `File.ReadAllText` によって UTF-8 として内容を読み込み、`fileContent` に保持します。読み込み中に例外が発生した場合は、`Messages.E00003` と例外メッセージを表示して終了します。

この処理により、後続の Lexer が解析する入力ソースをファイルから安全に取得します。

## 出力ファイルの拡張子取得

2 個目の引数を出力ファイル名として取得し、最後の `.` の位置から拡張子を抽出します。

- 拡張子がない場合は `Messages.E00008` を表示します。
- 拡張子がある場合は、`.Substring` で拡張子部分を `targetfileNameExtension` に保存します。

この拡張子は、将来的に C#、Java、VB.NET などの出力先を判定し、対応するコード生成器を選択するために利用する想定です。

## 56 行目までの処理の位置付け

56 行目までの追加コードは、字句解析・構文解析・意味解析・コード生成を実行する前段階の入力受付処理です。現時点では、次の 2 つの値を取得して保持するところまでが実装されています。

- 入力ファイルの内容: `fileContent`
- 出力ファイルの拡張子: `targetfileNameExtension`

`TargetLang` の定数および `targetfileNameExtension` は、56 行目までの範囲ではまだターゲット言語の分岐や生成器の選択には使われていません。後続処理でこれらを利用し、出力先に応じた `CSharpCodeGenerator`、`JavaCodeGenerator`、`VbNetCodeGenerator` の選択につなげるための準備段階です。
